Observabilidade — Fase 8

Este tutorial mostra como iniciar Prometheus e Grafana, expor as métricas do Open Wealth e verificar os principais indicadores.

1. Inicie os serviços de monitoramento

Na raiz do repositório, suba os containers:

docker compose up -d prometheus grafana

O Prometheus fica disponível em localhost:9090 e o Grafana em localhost:3000. Os volumes prometheus_data e grafana_data preservam os dados entre reinicializações dos containers.

2. Inicie a API

Em outro terminal, inicie o banco e a API conforme a configuração local do projeto. O alvo configurado no Prometheus espera a API na porta 8000: 

docker compose up -d db
./.venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000

O lifespan inicializa o banco e carrega o snapshot mais recente nos gauges de negócio durante o startup.

3. Confira a coleta

Confirme que a API expõe métricas no formato Prometheus:

curl http://localhost:8000/metrics

Em Prometheus → Targets, o alvo open-wealth-api deve aparecer como UP.

4. Consulte indicadores

As métricas incluem patrimônio, quantidade de contas e investimentos, duração das sincronizações e falhas reportadas pela Pluggy. Exemplos de consultas PromQL:

open_wealth_total_patrimonio_brl
open_wealth_accounts_total
open_wealth_investments_total
histogram_quantile(0.95, rate(open_wealth_sync_duration_seconds_bucket[5m]))
rate(open_wealth_pluggy_errors_total[5m])

A taxa de falhas pode ser acompanhada pela taxa de incremento do contador de erros em uma janela de tempo; zero amostras significa nenhuma falha observada nessa janela.

5. Grafana

No Grafana, configure Prometheus como fonte de dados usando http://prometheus:9090 na rede do Compose e crie painéis com as consultas acima. Os dashboards salvos são mantidos no volume grafana_data.

Para uso fora de uma máquina local, altere as credenciais padrão definidas no Compose e restrinja o acesso às interfaces de monitoramento.
