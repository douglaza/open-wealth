Alocação Multiclasse, Gestão de Risco e Consolidação Híbrida

Saber apenas o saldo total não basta: um patrimônio de R$ 500 mil concentrado em uma única ação ou banco é radicalmente diferente de uma carteira balanceada. A Fase 5 introduz o motor de Analytics, classificando ativos em classes macro, medindo exposição custodial e combinando contas automáticas da Pluggy com bens e passivos manuais (imóveis e financiamento imobiliário Caixa).

1

Os Três Pilares Analíticos do Open Wealth

1. Alocação por Classes

Mapeamento dinâmico entre Renda Fixa (CDBs, LCIs, Tesouro Direto), Renda Variável (Ações, ETFs, FIIs) e Fundos Multimercado para garantir o equilíbrio do perfil de risco.

2. Risco de Custódia

Identificação de concentração excessiva em uma única corretora ou banco (ex: C6 Bank com 58,7%, Rico com 41,3%), evitando exposição além dos limites do FGC.

3. Balanço Patrimonial Real

Cálculo matemático rigoroso: Patrimônio Líquido = Ativos Brutos (Bancos + Corretoras + Imóveis) - Passivos (Financiamentos + Faturas de Cartão).

2

O Motor de Classificação: app/services/analytics.py

A API do Open Finance retorna uma multiplicidade de nomenclaturas. O Open Wealth adota um algoritmo heurístico de classificação multiclasse resiliente a variações de campos:

app/services/analytics.py • Classificação Resiliente de Ativos Python 3.12 
def is_equity_investment(inv: Investment) -> bool:
    """Identifica ações, FIIs e fundos de ações mesmo com discrepâncias na Pluggy."""
    inv_type = (inv.type or "").upper()
    category = (inv.category or "").upper()
    name = (inv.name or "").upper()

    # 1. Tipo explícito de Equity
    if inv_type in ("EQUITY", "STOCK", "SHARE"):
        return True

    # 2. Fundos de Ações (FIA / AÇÕES no nome)
    if inv_type == "MUTUAL_FUND" and ("FIA" in name or "AÇÕES" in name or "ACOES" in name):
        return True

    # 3. Categorias e tickers clássicos da B3 (ex: PETR4, ITUB4, PSSA3)
    if any(k in category for k in ("AÇÃO", "ACAO", "VARIABLE", "RENDA_VARIAVEL")):
        return True

    return False

Consolidação Híbrida: Pluggy + Bens e Passivos Manuais

Muitos investidores têm imóveis ou dívidas imobiliárias estruturadas que ainda não trafegam via Open Finance automatizado. O Open Wealth une os dois mundos com o repositório ManualAssetRepository:

🏢 Ativos Manuais (Bens)

Exemplo: Apartamento Residencial valorizado a R$ 420.000,00. Contabilizado no ativo não-circulante (imobilizado).

🏦 Passivos Manuais (Dívidas)

Exemplo: Financiamento Habitacional Caixa com saldo devedor de R$ 180.000,00. Abatido do Patrimônio Bruto para gerar o Patrimônio Líquido real de R$ 240.000,00.

Métricas de Concentração Institucional

A agregação por instituição calcula o percentual de cada custodiante sobre o total investido:

app/services/analytics.py • Concentração de Custódia Python 3.12 
def calculate_institution_concentration(positions: list[Position]) -> dict[str, float]:
    total_val = sum(p.amount for p in positions if p.amount > 0)
    if total_val == 0.0:
        return {}

    by_institution: dict[str, float] = defaultdict(float)
    for p in positions:
        if p.amount > 0:
            by_institution[p.institution] += p.amount

    return {
        inst: round((val / total_val) * 100.0, 1)
        for inst, val in sorted(by_institution.items(), key=lambda x: x[1], reverse=True)
    }
