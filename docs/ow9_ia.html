✨ Efeito "Uau" com Engenharia de Contexto

Assistente Patrimonial Inteligente com LLM e Métricas Determinísticas

A Fase 9 introduz um consultor executivo que transforma números frios de carteira em respostas analíticas imediatas em linguagem natural. A chave da engenharia não é perguntar direto ao modelo, mas alimentar um Context Engine em Python que calcula os números com precisão matemática antes da inferência.

Arquitetura da Solução e Fluxo de Dados

Fluxo Ponta a Ponta

  1. 1. Pergunta do Usuário Chat Streamlit (dashboard/pages/insights.py) envia a pergunta via POST HTTP.
  2. 2. API FastAPI & Métricas POST /api/v1/insights/chat inicia cronômetro de latência e invoca o serviço.
  3. 3. ContextBuilder (Python Determinístico) Calcula variação 90d, custodiante líder, alocação RV/RF e dívidas consolidadas.
  4. 4. InsightsService & LLMClient Injeta contexto imutável no prompt executivo e despacha para Ollama ou OpenAI.
  5. 5. Resposta ao Usuário Retorna resposta analítica e objeto context_used para auditoria/expansor.

Desacoplamento em Camadas

Domain (app/domain/insights.py) Modelos Pydantic imutáveis: PortfolioContext, InsightChatRequest, InsightChatResponse.
Integrations (app/integrations/llm_client.py) Protocolo tipado BaseLLMClient com implementações: OllamaLLMClient, OpenAILLMClient e MockLLMClient.
Services (app/services/) ContextBuilder (cálculos numéricos) e InsightsService (orquestrador de prompt).
API & Presentation (app/api/ & dashboard/) Injeção de dependências no FastAPI e interface interativa em Streamlit.
2

Engenharia de Prompt & Lições de Implementação

🛡️ Prevenção de Alucinação

Nunca peça para uma LLM calcular percentuais ou variações patrimoniais. A regra inegociável do sistema é: "NUNCA calcule números. Use estritamente os valores fornecidos no contexto."

🏷️ Normalização de Renda Variável

O Pluggy expõe ativos com type="EQUITY" ou MUTUAL_FUND com sufixos "Ações" e "FIA". O ContextBuilder inspeciona tipo, categoria e nome para somar ações com exatidão.

⚡ Otimização CPU com Ollama

Em máquinas virtuais ou CPUs locais, gerar respostas longas causa timeout (>90s). A configuração de num_predict: 120-180 restringe a saída e reduz o tempo de resposta em até 70%.

Como Executar Localmente

Terminal 1 • Provedor de IA (Ollama Local) llama3.2:1b

# Instalar e iniciar o modelo ultraleve para CPU

$ ollama run llama3.2:1b

Terminal 2 • Backend FastAPI porta 8000

# Configurar provedor e iniciar Uvicorn

$ export LLM_PROVIDER=ollama

$ export OLLAMA_MODEL=llama3.2:1b

$ ./.venv/bin/uvicorn main:app --reload --host 0.0.0.0 --port 8000

Terminal 3 • Dashboard Streamlit porta 8501

# Iniciar a interface Web

$ streamlit run dashboard/Home.py
