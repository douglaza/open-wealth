A Jornada Completa do Open Wealth: Do MVP ao Assistente de IA

O Open Wealth é uma plataforma full-stack de consolidação patrimonial pessoal que agrega contas e investimentos via Open Finance (Pluggy), combina bens e passivos manuais (imóveis e financiamento habitacional Caixa), persiste histórico temporal idempotente e expõe dados através de API REST (FastAPI), Dashboard Web (Streamlit), Observabilidade SRE em tempo real (Prometheus + Grafana) e Assistente de IA com Context Engine determinístico (Ollama/OpenAI).

•

Arquitetura Integrada e Fluxo do Dado

Como as 9 fases se conectam ponta a ponta na Clean Architecture.

1. Coleta & Valoração (Fases 1, 5)

Conexão com a API Pluggy, paginação de transações v2 e leitura de ativos e passivos manuais. Aplicação da cascata estrita: balance → qty * price → amount → 0.0

2. Persistência & Sync (Fases 2, 3, 6)

Orquestração agendada às 09:00 BRT pelo APScheduler. Gravação diária em SQLite/PostgreSQL com verificação de idempotência para evitar duplicidade.

3. Exposição & IA (Fases 4, 7, 8, 9)

Endpoints REST FastAPI, métricas Prometheus em tempo real, painéis Grafana, suíte com 100% de cobertura e chat com IA alimentado por Context Engine determinístico.

Open Finance / Manual → Domínio & Cascata → Snapshots Idempotentes → FastAPI & Streamlit → Prometheus / Grafana → Context Engine + LLM

Guia Rápido de Execução da Plataforma

Comandos essenciais para subir toda a stack em ambiente local ou VM.

1. Subir Infraestrutura SRE (Prometheus & Grafana) 
docker compose up -d
# Prometheus em http://localhost:9090 | Grafana em http://localhost:3000
2. Iniciar Backend FastAPI (com Scheduler ativo) 
export LLM_PROVIDER=ollama
export OLLAMA_MODEL=llama3.2:1b
./.venv/bin/uvicorn main:app --reload --host 0.0.0.0 --port 8000
3. Iniciar Dashboard Streamlit 
./.venv/bin/streamlit run dashboard/Home.py
4. Garantir Qualidade e Testes (100% Cobertura) 
ruff check . && mypy app && pytest --cov=app --cov-report=term-missing
